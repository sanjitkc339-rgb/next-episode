# Next Episode

A lightweight, client-side web application that helps you pick what anime to watch based on your mood.

## Features
- **Mood-based Picking**: Choose a mood (Cozy, Hyped, Funny, etc.) and let the app recommend an anime.
- **Browse & Search**: View the full list of recommendations, filter by genre, and search by title.
- **Watchlist**: Save anime to your personal watchlist using local storage.
- **Dark Mode Support**: Adapts to your system theme, with a manual toggle.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## How to use
Simply open `index.html` in your web browser. No build steps or server required.

## Data
The anime list is embedded directly into the application, including scores, genres, and a short blurb for each.
